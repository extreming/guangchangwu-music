# 广场舞音乐

给家里老人用的微信小程序：从抖音、快手、抖音火山版的分享文字里取出舞曲，存进小程序的「我的音乐」，用很大的按钮播放，并且可以单曲循环，方便反复练舞。

本项目以 [MIT License](LICENSE) 开源，版权所有 (c) 2026 extreming。

文件名用视频标题整理后的名字，例如 `夕阳红广场舞.mp3`，转发出去也好认。

## 老人怎么用

1. 在抖音或快手打开要跳的舞，点「分享」，再点「复制链接」。
2. 回到小程序，点 **粘贴链接**，再点 **提取音乐**。
3. 进入播放页，点大大的 **播放**。**重复播放** 默认开着，播完会再来一遍。
4. 下次直接打开 **我的音乐**。

练舞不需要把文件存进手机文件夹。「我的音乐」里的歌存在这个小程序里面，锁屏后也尽量继续放（需要微信允许后台音频；若失败，屏幕请保持亮着）。音量用手机侧面的按键。

请不要在微信里删除这个小程序，否则已经存的音乐会一起消失。微信给小程序的本地空间大约 200MB，歌多了可以先删旧的。

### 还想存进手机文件夹

小程序不能直接把文件写进手机的「文件」或音乐库。播放页有 **发给文件传输助手** 和 **看图：存到手机**。

安卓：发给「文件传输助手」→ 点开文件 → 点「保存」或「用其他应用打开」。

苹果：微信没有“直接存进文件 App”的接口。发给「文件传输助手」→ 点开文件 →「用其他应用打开」→「存储到文件」。也可以复制下载链接，用 Safari 粘贴后下载。复制出来的链接大约 2 小时内有效，请马上用。

`wx.shareFileMessage` 必须由用户点按钮触发，所以「发给文件传输助手」是单独的一步，不能在提取完成时自动弹出。

## 目录

```
miniprogram/     小程序（原生 WXML / WXSS / JS）
backend/         解析、下载、ffmpeg 转 MP3 的服务
design/          步骤示意图的生成脚本
docker-compose.yml
project.config.json
```

平台解析是分开的，网站改版时只改对应文件和测试样例：

| 平台 | 代码 |
| --- | --- |
| 抖音 | `backend/app/parsers/douyin.py` |
| 快手 | `backend/app/parsers/kuaishou.py` |
| 抖音火山版 | `backend/app/parsers/huoshan.py` |
| 普通网页、直链音视频 | `backend/app/parsers/generic.py` |
| 从分享文字里抠出网址 | `backend/app/parsers/linktext.py` |

分享文字里的短链会先跟着跳转解开。抖音、快手、火山优先用页面里的音乐地址；音乐地址失败时，再下载视频并用 ffmpeg 抽出音轨，输出 128kbps MP3。

## 本地运行后端

需要 Python 3.11+ 和本机的 `ffmpeg`、`ffprobe`（含 libmp3lame）。

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8765
```

健康检查：<http://127.0.0.1:8765/api/health>

```bash
curl -s http://127.0.0.1:8765/api/health
```

提取（把分享文字放进 `text`）：

```bash
curl -s http://127.0.0.1:8765/api/extract \
  -H 'content-type: application/json' \
  -d '{"text":"https://v.douyin.com/xxxx/"}'
```

成功时返回 `title`、`filename`、`audio_url`。小程序会立刻把这个地址下载进「我的音乐」。服务器上的临时文件默认 2 小时后删除，不保存用户贴进来的原文。

### 测试

测试不访问抖音、快手、火山的真实网站，平台页面用本地样例，转码用 ffmpeg 生成的 1 秒视频。

```bash
cd backend
python -m pytest
```

### Docker

在仓库根目录：

```bash
docker compose up --build
```

容器里已经安装 ffmpeg。数据卷是 `/data`。对外端口 `8765`。部署到公网时，把 `PUBLIC_BASE_URL` 改成 `https://你的域名`（不要带端口，见下文）。

## 用微信开发者工具打开

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 导入项目，目录选**本仓库根目录**（这里有 `project.config.json`，`miniprogramRoot` 指向 `miniprogram/`）。
3. AppID 目前是占位 `wx0000000000000000`。没有正式号时，在导入窗口选「测试号」。有自己的小程序后，改 `project.config.json` 里的 `appid`，或在开发者工具里填写。
4. 详情里勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`project.config.json` 里 `urlCheck` 已是 `false`，只对开发者工具有效。
5. 先启动上面的后端。小程序请求地址在 `miniprogram/config.js` 的 `apiBase`，默认 `http://127.0.0.1:8765`。
6. 基础库使用 3.5.5。后台播放依赖 `app.json` 的 `requiredBackgroundModes: ["audio"]`。

真机预览不能访问电脑的 `127.0.0.1`。手机上要用，后端必须是公网 HTTPS。

## 配置服务器域名（上线必做）

微信要求：

- 接口是 **HTTPS**，默认 443 端口。不能写 IP，不能写 `http://`，不能带 `:8765` 这类端口。
- 域名做了 **ICP 备案**，并配置到小程序后台的服务器域名：
  - **request 合法域名**：调用 `POST /api/extract`
  - **downloadFile 合法域名**：下载 MP3（和 request 用同一个域名即可）
- 不需要 uploadFile、socket 域名。
- 改好域名后，把 `miniprogram/config.js` 的 `apiBase` 设为 `https://你的域名`，后端环境变量 `PUBLIC_BASE_URL` 设成同一个地址，否则复制出来的下载链接还是内网地址。
- 若设置了 `API_TOKEN`，把同样的字符串填进 `config.js` 的 `apiToken`。下载文件的链接本身不带口令（老人要在浏览器里打开），靠一长串随机 id，并在数小时后失效。
- 用户隐私保护指引里声明「读取剪贴板」，用途写：读取用户复制的分享链接，以便提取音乐。开发阶段如果弹出隐私协议拦截，可以在输入框里长按粘贴。

后台音频：上传代码时保留 `requiredBackgroundModes`。若类目不允许后台播放，审核会指出；那时可以删掉这一项，播放会退回到「页面打开时才出声」。

## 审核风险（请先看）

微信审核经常拒绝「视频解析、去水印、无水印下载、短视频保存」这类工具，甚至限制相关能力。本项目会根据用户粘贴的公开分享链接下载媒体并抽出音轨，**存在被认定为此类工具而不通过的风险**。这里不能保证能审核通过。

降低被拒概率的做法（仍然不保证）：

- 类目优先考虑 **工具 → 实用工具**，或音乐播放相关类目（以当时可选类目为准）。不要选看起来像「影视解析」的类目。
- 名称用「广场舞音乐」「舞曲收听」这一类。不要用「去水印」「解析」「抖音下载」「无水印」做名称、简介、截图里的字。
- 简介可以写：帮助中老年用户把自己复制的公开分享保存为舞曲，在小程序内循环播放，供个人练舞。页面上已经是这套说法。
- 准备版权说明：仅个人学习练舞，权利属于原作者，不得商用、不得再传播。小程序底部有同样的一句话。
- 审核材料不要放「批量下载」「破解」的演示。

若被拒，按驳回原因改文案或下线解析能力，不要用规避词反复撞审。

## 环境变量

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| `PUBLIC_BASE_URL` | `http://127.0.0.1:8765` | 返回给小程序的文件地址前缀 |
| `DATA_DIR` | `backend/data` | 临时 MP3 目录 |
| `FILE_TTL_SECONDS` | `7200` | 临时文件保留时间 |
| `MAX_DOWNLOAD_MB` | `100` | 单个视频下载上限 |
| `MAX_DURATION_SECONDS` | `1200` | 最长 20 分钟 |
| `RATE_LIMIT_PER_MINUTE` | `10` | 每个 IP 每分钟提取次数 |
| `API_TOKEN` | 空 | 非空时，提取接口要带请求头 `X-Api-Token` |
| `TRUST_PROXY` | 空 | 设为 `true` 时才信任 `X-Forwarded-For` |
| `PORT` | `8765` | 仅 Docker 启动命令使用 |

服务会拒绝访问本机、内网和云厂商元数据地址，避免被当成内网探针。

## 已验证和未验证

已在本机用自动化测试验证：

- 从带口号、中文、零宽字符的分享文字里抽出网址，并认出抖音、快手、火山版。
- 用本地样例解析抖音接口 JSON、`RENDER_DATA` 页面、快手页面、火山版 JSON、普通网页里的 `<audio>` / `<video>` / JSON-LD。
- 音乐地址返回的是网页时，改用视频地址再转码。
- ffmpeg 从一段真实生成的 MP4 里抽出 MP3，接口能按歌曲名下载。
- 过期文件清理、访问频率限制、拒绝内网地址和跳转到内网的链接。

没有做、也不能当成已经可用：

- 没有请求真实的抖音、快手、火山版。这些站点经常改页面、要签名，机房 IP 也常被拒绝。解析器按公开页面里常见的字段来写，上线后某个平台坏了，只改上表里的那一个文件。
- 没有在真机微信里点过「发给文件传输助手」。苹果尤其依赖微信和系统版本，失败时用「复制下载链接」。
- 分段的 m3u8 播放列表暂不支持（交给 ffmpeg 直接打开远程地址会绕过内网防护，因此直接拒绝）。
- 小程序界面是按微信组件写的，本环境没有微信开发者工具，没有在模拟器里点过。请导入后自己走一遍：粘贴、提取、播放、重复、我的音乐、看图。

## 接口

- `GET /api/health` → `{ "status": "ok", "ffmpeg": true }`
- `POST /api/extract`，JSON：`{ "text": "分享文字或链接" }`
- `GET /api/files/{id}` → `audio/mpeg`，`Content-Disposition` 使用整理后的文件名

失败时 HTTP 状态和正文里的 `error` 都是给用户看的简短中文，例如「没有找到链接」「这首太长了」「操作太频繁」。
